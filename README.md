# Gita Journal

A private, Socratic reflection space grounded in the Bhagavad Gita — built for the Hack2Skill Ideathon Challenge.

## What this is

A secure, user-authenticated journaling app. You write freely about how you are feeling; the app responds as a reflective, Socratic guide — asking a clarifying question before offering guidance — and once a theme is clear, surfaces a verified Bhagavad Gita verse with grounded practical guidance. It remembers your past reflections, isolated to you alone, and notices when a theme echoes something you have reflected on before.

## Core features

- Scriptural grounding — verses are hand-sourced and verified, never generated by the model.
- Socratic interaction pattern — a clarifying question before guidance, unless directly asked.
- Pattern Recall — surfaces echoes of past entries with strict no-repeat verse preference.
- Crisis & Care Safeguard — real distress bypasses scripture entirely, routing to Tele MANAS (1-800-891-4416 / 14416) and iCall (9152987821).
- Model resilience — a four-model Gemini fallback ladder so a single outage does not break the app.

## Extended features

- Emotional Vault — a timeline of reflections mapped to Sattva/Rajas/Tamas states, with peak and valley moments.
- Geotagging — optional, permission-gated location tagging on entries, with named sanctuary presets.
- Guided Prompts — quick-start entries for common situations (burnout, self-doubt, grief, decision paralysis).
- Pranayama centering — a pre-reflection breathwork exercise before writing.
- Daily contemplation reminders — streak tracking, browser notifications, and calendar sync.

## Firestore security rules

Owner-scoped access for both the user document and nested entries:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /entries/{entryId} {
        allow read, write, delete: if request.auth != null && request.auth.uid == userId;
      }
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

Deploy with: firebase deploy --only firestore:rules
